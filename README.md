## Шаблоны GitHub

В репозитории находятся общие шаблоны Issues и Pull Request. GitHub применяет
их в репозиториях организации, если в конкретном репозитории нет собственного
шаблона того же типа.

## Область действия

Этот репозиторий не заменяет локальную документацию конкретного продукта.
Правила, зависящие от аппаратной платформы, языка, сборки или поставщика,
должны храниться в соответствующем рабочем репозитории.
