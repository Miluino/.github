# Шаблоны и настройки GitHub Miluino

Этот репозиторий содержит общие шаблоны и настройки GitHub для репозиториев организации [Miluino](https://github.com/Miluino).

> [!IMPORTANT]
> AI-агенты перед анализом или изменением этого репозитория обязаны прочитать [общие правила работы AI-агентов](https://github.com/Miluino/dev-guidelines/blob/master/ai-agents.md), затем только относящиеся к задаче документы и файлы. Полный рекурсивный анализ репозитория без необходимости не выполняется.

## Шаблоны GitHub

В репозитории находятся общие шаблоны Issues и Pull Request. GitHub применяет их в репозиториях организации, если в конкретном репозитории нет собственного шаблона того же типа.

## Область действия

Этот репозиторий содержит только общие шаблоны и настройки GitHub. Правила разработки, инструкции по Git, стилю кода и работе с Issues и Projects хранятся в `dev-guidelines`.

Этот репозиторий не заменяет локальную документацию конкретного продукта. Правила, зависящие от аппаратной платформы, языка, сборки или поставщика, должны храниться в соответствующем рабочем репозитории.
